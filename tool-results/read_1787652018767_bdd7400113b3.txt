   162→## Completed
   163→
   164→Rewrote `src/components/tuner-gauge.tsx` from a horizontal linear bar gauge to a **premium SVG-based semicircular arc gauge** (speedometer style).
   165→
   166→### Design
   167→- **Semicircular arc** (180°, left=-50 cents flat, right=+50 cents sharp) with SVG `<path>` and `<circle>` elements
   168→- **60 coloured arc segments** using `strokeDasharray` / `strokeDashoffset` technique on a shared semicircle path — each segment is 1.67 cents wide, producing a **smooth gradient** from dark-red (±50) → red (±25) → orange (±10) → yellow (±5) → emerald (0)
   169→- **17 tick marks** at -50,-40,-30,-25,-20,-15,-10,-5,0,5,10,15,20,25,30,40,50 with 3 tiers (major at 0/±50, mid at ±25, quarter at ±10/±40) and labelled cent values at major ticks
   170→- **Spring-physics needle** (Framer Motion `motion.g` with `type: 'spring', stiffness: 260, damping: 26, mass: 0.9`) — tapered polygon with drop-shadow filter, bright tip circle, and layered centre pivot
   171→- **Pulsing emerald glow** (SVG `feGaussianBlur` filter + Framer Motion animate on needle-tip circle) when `isAccurate` (≤5 cents)
   172→- **Centre display** inside the semicircle: large solfege Persian text (دو رِ می فا سل لا سی) with spring entrance animation, note name + octave + frequency below
   173→- **Volume bar** at the top (thin gradient bar rose→amber→yellow)
   174→- **Accuracy feedback** below arc: "عالی" / "خوب" / "قابل قبول" / "فالش" with matching colour, cents label, and direction text ("بم ←" / "→ زیر" / "کوک دقیق")
   175→- **`dir="ltr"` wrapper** — arc follows musical convention (left=flat, right=sharp) even in RTL page
   176→- **Dark mode** via Tailwind `dark:` classes on SVG elements using `currentColor` + `className`
   177→- **Responsive**: `max-w-xs sm:max-w-sm md:max-w-md`, solfege text `text-5xl sm:text-6xl lg:text-7xl`
   178→
   179→### SVG Math
   180→- Centre: (150, 150), Radius: 120, ViewBox: `0 0 300 165`
   181→- `centsToAngle(c) = 180 - ((c+50)/100) * 180` — maps -50→180°, 0→90°, +50→0°
   182→- Needle rotation: `needleAngle - 90` (needle drawn pointing up, rotated to target)
   183→- Arc path uses sweep-flag=0 for upper semicircle (counter-clockwise in SVG y-down)
   184→- All static geometry (segments, ticks) pre-computed at module level — zero re-computation per render
   185→
   186→### Props Interface (unchanged)
   187→```typescript
   188→interface TunerGaugeProps {
   189→  cents: number; noteName: string; solfege: string;
   190→  octave: number; frequency: number; isAccurate: boolean;
   191→  isActive: boolean; volume: number;
   192→}
   193→```
